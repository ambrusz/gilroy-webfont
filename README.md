# Gilroy webfont

Gilroy webfonts (woff2 + woff) for use in Stripo / web, served via jsDelivr. Licensed font – used under the owner's license.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ambrusz/gilroy-webfont@main/gilroy.css">
```

```css
font-family: 'Gilroy', Arial, sans-serif;
```

Weights: 300 Light, 400 Regular (+ italic), 500 Medium, 600 SemiBold, 700 Bold, 900 Black.
